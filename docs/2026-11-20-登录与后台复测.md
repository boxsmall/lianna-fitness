# 登录、用户同步和可选项修复

## 本次调整

- 热量估算的两个开关可关闭或省略，三种目标都可预览保存；未选择不会被当成健康状况不适用。年龄、单位、适用范围和能量下限校验保留。
- 微信身份登录与昵称头像填写分开。用户在「我的 → 完善资料」主动选择头像、填写昵称并确认保存，可跳过。不会自动读取微信昵称头像。
- 头像限256KB的PNG/JPEG/WebP，经已登录接口上传，昵称与头像同步到后台列表和详情。重复提交幂等，注销清理头像。
- 后台有效登录会话在刷新时保留并由服务器重新验证；验证期间显示加载状态。暂时断网提供重试入口，不误报退出。退出、失效或撤权后要求重登，管理员新会话期限8小时。
- 服务端明确拒绝空密码、错误密码和伪造凭证；失败登录不会创建无效管理员元数据。
- 用户列表每30秒更新，返回列表或切回窗口时刷新，支持手动刷新。输入筛选及编辑弹窗期间避免自动刷新打断操作。
- 补回食材管理、营养与热量规则侧栏入口；新增昵称头像动态中文说明。
