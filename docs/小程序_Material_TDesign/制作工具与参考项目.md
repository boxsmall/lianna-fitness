# 小程序改版制作工具与参考项目记录

日期：2026-11-20
项目：练哪小程序 · Material × TDesign 设计改版
交付目录：`docs/小程序_Material_TDesign/`

## 本次结果

基于原第二版 15 页设计，统一手机页面的颜色角色、字号、表面层级、导航、按钮、表单与底部弹层。重点调整“新建今天训练 → 多选动作 → 追加 → 改组次 → 保存”流程；“替换动作”使用独立操作，避免追加时覆盖已有动作。

交付包含可点击 HTML 原型、15 页截图、设计总览、组件对应表、WXSS 主题变量及验收记录。本提交是设计交付，不代表生产网站或微信小程序已部署；TDesign 小程序运行时尚未集成。

本轮视觉改版以原第二版设计稿为基础。提交前同步发现远端已有二版小程序与业务服务实现，已将其历史纳入本地提交基线。本次新增目录是独立设计交付，不覆盖 `微信小程序/` 或 `二版后台/` 的实现；本记录中的“未接入”描述仅指本设计原型。

## 复现与继续开发

在仓库根目录运行：

```sh
python3 -m http.server 8003 --directory "docs/小程序_Material_TDesign"
```

浏览器打开 `http://localhost:8003/index.html` 看页面目录，打开 `http://localhost:8003/mobile.html#today` 体验原型。也可下载完整目录后离线打开 `index.html`。页面与素材无需前端构建步骤。

- `mobile.js`：页面与交互；草稿保存在当前浏览器的独立 localStorage 键 `lianna-mtd-v1` 中。
- `material-tdesign.css`：本轮视觉主题；`style.css`：保留的原型结构样式。
- `icons.js`：TDesign 官方图标。
- `theme.wxss`：微信小程序的通用主题变量交接。
- `设计说明.md`：设计依据、组件对应与交付边界。
- `验收记录.md` / `responsive-checks.json`：人工可读验收与 45 组适配检查结果。

本原型没有服务端、真实微信授权或云同步；营养与训练数值属于示例。自动排周、饮食搭配和训练记录尚不能作为完整生产算法或数据实现验收。正式开发应使用稳定的训练与动作实例 ID，并完成微信开发者工具验证。

## 验证与资源许可

本轮覆盖 15 个页面 × 375、390、430 三种宽度；验证了跨分类多选、追加第 4 个动作、单独替换第 1 个动作、修改组次及保存反馈。具体证据与限制见[验收记录](验收记录.md)。

TDesign 图标许可见 `TDESIGN-ICONS-LICENSE.txt`。沿用的训练素材与来源说明位于 `assets/来源说明/`，原项目的署名和使用条件继续保留。
