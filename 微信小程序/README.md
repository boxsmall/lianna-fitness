# 练哪 · 微信小程序

原生微信小程序，AppID 为 `wx30a87cd4d4c6e9c1`。小程序包含挑动作、选择器械、动作详情、我的收藏四个页面。无需登录，器械和收藏保存在当前微信小程序的本地存储中，独立于网页版。

## 在另一台电脑导入

1. 解压交接包，或从项目源码中取出整个 `微信小程序` 目录。
2. 用具有该 AppID 开发权限的微信账号登录微信开发者工具，选择「小程序 → 导入」，目录选中含 `project.config.json` 的 `微信小程序` 文件夹。确认 AppID 显示为 `wx30a87cd4d4c6e9c1`。
3. 直接编译。项目中已包含全部动作数据、器械图片及原生页面代码，导入时无需安装 npm 依赖、运行同步脚本或复制网站目录。
4. 在小程序管理后台的开发设置中核对服务器域名，将 `https://lianna.yijiandot.com.cn` 加入 downloadFile 合法域名。封面与演示使用该站点的 HTTPS 网络图片。保持开发者工具的域名和证书校验开启，然后用「预览」在微信中验证。交接包不含 AppSecret。

微信参考文档：[image 组件](https://developers.weixin.qq.com/miniprogram/dev/component/image.html) · [网络与服务器域名](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。

## 数据和资源

- 1,324 个正式动作、8 个训练部位、98 项器械。8 个热身动作已计入动作总数。
- `miniprogram/data/catalog.js` 包含与网站相同的动作编号、分类、动作说明和 69 项修订所保留的原始说明。详情页展示当前修订文字。
- 器械参考图随包提供。动作封面和循环演示按需从网站读取，使用网站的素材版本号。媒体地址配置在 `miniprogram/lib/catalog.js`。需要联网查看演示。
- 拥有的器械与本次使用的器械分别保存。清空筛选后保留器械清单。需要多件器械的动作按整套要求匹配，支持数据中登记的替代器械。
- 热身按训练部位推荐，可在「热身」或对应目标肌群下查看。跨部位推荐的热身在列表中标明收藏归属，收藏始终按动作本身的部位分组。
- 如网站数据更新，在完整仓库中使用 Python 3.9+ 和 Pillow 运行 `python3 微信小程序/scripts/sync-catalog.py`，再重新导入或编译。脚本读取同级 `网站代码/dist`，将器械 WebP 转为本地 JPEG，并保留器械 SVG。

## 异机验收顺序

| 操作 | 预期结果 |
| --- | --- |
| 先选肩部，再选哑铃 | 器械列表显示参考图，不适配所选部位的器械在「本次使用」中置灰；「三角肌」中可打开哑铃侧平举。 |
| 清空筛选，再只选健身车 | 正式训练中，只有与该器械匹配的部位可以选。「已拥有」仍保留之前添加的器械。 |
| 只选哑铃，选肩部，切换到「热身」 | 弹力带 Y 字上举仍出现；肩胛骨俯卧撑标记「收藏归入胸部」。 |
| 选「全身 → 热身」，收藏膝关节绕环 | 在「我的收藏 → 臀腿」能找到该动作。 |
| 从列表收藏哑铃侧平举，再打开详情 | 详情展示肩部、三角肌、器械和动作说明；观察完整循环，确认双臂抬起、放下。在详情取消收藏，返回列表和收藏页均同步。 |
| 打开 0858 和 3224 | 分别显示「悬垂交替提膝」「深蹲分腿触脚跳」，核对说明和实际动图。在 iOS、Android 微信中分别观察循环及切换动作后的播放。 |
| 保存器械与收藏，退出后重开 | 已拥有、本次使用和收藏均保留。若网络中断，已打包的文字与器械参考图仍可查看，动图失败后可点「重新加载」。 |
